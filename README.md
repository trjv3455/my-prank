# Interactive Web Demo
> 原生 JavaScript 移动端交互演示项目

## 📌 项目简介
本项目是一个前端交互练习Demo，基于原生HTML/CSS/JavaScript实现多阶段页面状态切换、动态视觉动画与媒体播放控制，针对移动端浏览器做适配优化，解决移动端触摸事件、视频自动播放等浏览器兼容性问题。

## 🛠 技术栈
- HTML5 + CSS3：页面布局、帧动画、viewport移动端适配
- 原生 JavaScript：触摸事件监听、页面状态机管理、媒体API控制
- 兼容性适配：微信内置浏览器、移动端视频播放策略处理

## ✨ 功能说明
1. 多状态页面流转：页面包含多个展示阶段，通过用户触摸交互触发状态切换
2. CSS动态视觉效果：实现页面抖动、颜色变化等动画渲染
3. 媒体资源控制：监听交互事件，触发视频播放，处理浏览器自动播放限制
4. 移动端适配：设置视口参数，适配手机竖屏浏览，支持触摸触发交互
